# 회원 관리 (관리자) v1.0

작성: 기획팀 · 2026-09-05

## 1. 회원 목록

- 검색: 이름 또는 이메일 (엔터 또는 검색 버튼)
- 필터: 상태(전체 / 정상 / 정지 / 탈퇴), 가입일 범위
- 컬럼: 이름, 이메일, 상태, 가입일, 최근 로그인, [상세] 버튼
- 페이지네이션 20건
- 빈 상태 문구: "조건에 맞는 회원이 없습니다"

## 2. 회원 상세

목록에서 [상세]로 진입.

- 기본 정보: 이름, 이메일, 휴대폰, 가입일, 최근 로그인, 상태
- 상태 변경: [정지] / [정지 해제] 버튼. 누르면 확인 팝업
- 활동 이력: 최근 10건 (일시 + 내용)

## 3. 비고

- 관리자 권한만 접근
- 탈퇴 회원의 개인정보는 마스킹 표시
